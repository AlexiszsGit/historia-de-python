La importancia de
leer el código

Python fue diseñado teniendo en cuenta la claridad del código y la facilidad para trabajar con él.

01

Una idea sencilla

La forma en que está escrito un programa importa. Cuando el código es fácil de entender, resulta más sencillo modificarlo, corregirlo y trabajar con otras personas.

Esta idea estuvo presente durante el diseño de Python y ayudó a darle una identidad propia frente a otros lenguajes de la época.

02

Algunos principios

01

Claridad

El código debe poder entenderse sin tener que descifrarlo constantemente.

02

Simplicidad

Una solución sencilla suele ser más fácil de mantener.

03

Practicidad

El lenguaje debe servir para resolver problemas reales.

03

El Zen de Python

Python también cuenta con una colección de principios conocidos como el Zen de Python. Estos principios resumen varias ideas relacionadas con la forma de escribir y pensar el código.

Su objetivo no es convertir la programación en una serie de reglas rígidas, sino servir como una referencia para mantener el código claro y sencillo.
